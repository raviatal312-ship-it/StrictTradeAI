# StrictTrade AI — Offline Paper Mode

This Android build works without Kotak Neo API credentials or a server.

Features:
- Offline manual market/signal analyzer
- CALL / PUT / WAIT scoring
- Trend, candle, VWAP, RSI, volume, Fibonacci, level and OI confirmations
- Manual premium-based Entry / SL / Target calculation
- Manual ATM strike suggestion using 50-point rounding
- Paper trading balance and order history
- No real-money order execution

Important: without an authorized live market-data source, the app does not claim to provide real-time prices or option-chain data. Enter values from your chart manually.

Build: Android Studio → open `android` → Build → Build APK(s).
